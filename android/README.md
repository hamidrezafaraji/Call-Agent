# Call Agent — اپ اندروید

جمع‌آوری تماس‌های گوشی کارشناس و ارسال به سرور Call Agent شرکت.

## چطور کار می‌کند
- **گزارش تماس‌ها** از API استاندارد اندروید خوانده می‌شود (روی همه‌ی برندها یکسان). فقط تماس‌های بعد از فعال‌سازی.
- **فایل ضبط** از ضبط‌کننده‌ی داخلی گوشی برداشته می‌شود. اپ مسیر پوشه را نمی‌داند و لازم ندارد:
  فایل‌های صوتی ایندکس اندروید (MediaStore) را می‌گردد و فایلی را که زمان پایانش و طولش با تماس جور است
  انتخاب می‌کند (`RecordingMatcher`). اگر گوشی فایل‌ها را ایندکس نکند، کاربر پوشه را دستی انتخاب می‌کند.
- **صف ارسال** در دیتابیس محلی؛ تا وقتی سرور در دسترس نباشد تماس‌ها روی گوشی می‌مانند.
  هر تماس تا ۳۰ دقیقه منتظر فایل ضبطش می‌ماند و بعد بدون صدا ارسال می‌شود.
- **همگام‌سازی** هر ۱۵ دقیقه (WorkManager) و دکمه‌ی «همگام‌سازی الان».
- **فعال‌سازی** با اسکن QR صفحه‌ی `/admin` سرور (ZXing، بدون نیاز به Google Play Services) یا ورود دستی.
- **بررسی سازگاری**: برای تماس‌های ۷ روز گذشته چک می‌کند چند تا فایل ضبط دارند (فقط روی گوشی).

## ساخت
- JDK 17، Android SDK 35، Gradle 8.10.2 (AGP 8.7.3، Kotlin 2.0.21)
- کتابخانه‌ها از سرورهای گوگل دانلود می‌شوند: **موقع ساخت VPN باید روشن باشد.**
- با Android Studio: پوشه‌ی `android/` را باز کنید.
- تست‌های واحد: `gradlew test` (منطق تطبیق فایل ضبط با تماس، QR و فرمت زمان)

شناسه‌ی برنامه `com.callagent.app` است؛ قبل از اولین انتشار عمومی اگر لازم است عوض شود.
